## 关键边界和验证范围

- SQL 任务仓库测试覆盖并发认领、过期令牌不能完成或重试、任务与结果事务回滚、租户条件、最终一次租约过期转失败、状态查询及历史回填。它不能单独证明真实多实例故障恢复；全栈用例通过过期租约和调度扫描验证恢复路径。
- 全栈测试要求显式启用，MySQL URL 限制为本机且库名以 `codex_ticket_test_` 开头；测试会在该库中修改管理员密码、创建租户与工单，并在正常退出时恢复密码。应使用专门的可丢弃测试库和独立 Redis，不能将其配置到现有业务实例。Redis 端口由环境变量指定，测试代码自身不验证其是否为独立实例；进程被强制终止也可能跳过清理。
- 真实 Spring 环境下，复用单工作线程依次处理两个租户，检查分类归属、跨租户不可见和自动写回时的用户字段；执行器现在在每次任务前后清除用户与租户上下文。
- 匿名访问的 401、管理员正常登录、创建、状态查询、版本冲突、规则兜底与全量表单已有全栈用例；无工单接口权限的低权限角色访问列表、详情和分类状态均返回 403。该用例不验证拥有工单接口权限的同租户用户之间的个人或部门隔离，项目本身定义为租户内共享。
- 已进行真实 DeepSeek 离线评测，但没有记录 token 用量或成本，且样本小、标注有争议；全栈应用测试仍使用无密钥规则兜底。未验证 PostgreSQL、真实浏览器交互、线上部署及真实进程重启。前端大包警告不影响本次构建成功，但仍有优化空间。
