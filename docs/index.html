AI 工单管理系统 · 文档

在 ContiNew Admin 之上自研的 AI 工单分类模块。工单提交后由大模型判定分类与紧急程度，模型不可用时自动降级为关键词规则。

离线接口手册推荐

单文件、无外部依赖。左侧按分组选接口，右侧看参数表，curl 示例可一键复制。

接口约定说明

Base URL、鉴权方式、字段术语表，以及三份产物各自适合什么场景。

工单接口文字版

9 个接口的完整说明，在 GitHub 上渲染成网页，可 Ctrl+F 搜字段名。（浏览器直接打开 .md 会触发下载，故指向仓库视图）
